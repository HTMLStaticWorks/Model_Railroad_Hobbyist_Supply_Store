Layout of the Month

The Great Western Cascade Route

Created by veteran club member Arthur Vance, this extraordinary HO scale layout takes up an entire double garage. It features a complete Appalachian logging line, detailed limestone quarry, functional switching terminals, and fully automated signal systems controlled by advanced DCC electronics.

Dimensions 24 ft x 16 ft (Double Deck)
Scale & Code HO Scale - Code 83 Track
Automation ESU CabControl & Block Detection
Build Duration 5 Years of Dedicated Crafting
